# Math300-NonLinear-Dynamics-In-Continuous-Time

## The project
We analyzed the Lotka-Volterra equations and Rössler attractor for this project. This includes defining the functions for each system, solving them, plotting the solutions against time for a few different initial states and parameter values, and checking the accuracy of the solver on an equation with known exact solution.
